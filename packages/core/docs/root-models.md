# core/src — модели, провайдеры и служебные сервисы ядра

## Назначение

Этот набор корневых файлов `packages/core/src` описывает, как opencode знает провайдеров, какие у них модели и как из записи каталога получается готовая к запросу модель. Здесь же лежат три независимых от модели сервиса: генерация одноразового текста, веб-поиск, форматирование файлов и нормализация картинок.

## Что в папке

Тринадцать файлов корня `src`: девять вокруг моделей (`provider`, `models-dev`, `model`, `variant`, `aisdk-native`, `aisdk`, `model-resolver`, `generate`, `app`) и четыре вспомогательных (`agent`, `websearch`, `formatter`, `image`). Все сервисы написаны на Effect: `Context.Service` + `Layer` + узел `makeLocationNode`/`makeGlobalNode` с явными зависимостями.

## Ключевые файлы

- `provider.ts` — реестр провайдеров. Тип `ID`, префикс `aisdk:`, `packageName()` снимает префикс и чинит старый scope `@opencode-ai/ai/` → `@opencode/`; `builtins` — карта из ~50 нативных пакетов `@opencode/ai/providers/*` на ленивый `import()`; `loadPackage()` ищет пакет, при отсутствии ставит корневой npm-пакет через `Npm` и резолвит entrypoint. Служба `Provider.Service` (`Editor`/`Interface`) держит `Map<ID, Definition>`, считает `snapshot()` с учётом интеграций и публикует `Provider.Event.Updated`. Здесь же утилиты слияния: `mergeOverlay` (глубокое слияние JSON-объектов), `mergeHeaders` (ключи в нижнем регистре), `timeouts()` и `DEFAULT_TIMEOUT_MS = 300_000`, разбор `CORE_KEYS`/`PROVIDER_ONLY_KEYS`.
- `models-dev.ts` — источник каталога моделей. Приоритет: локальный файл (`options.file`) → KV-кэш → вшитый снапшот `models-dev/snapshot.txt` → сеть `https://models.opencode.ai/api.json`. `normalize()` превращает запись провайдера в `Snapshot { info, models, environment }`, разворачивает `experimental.modes` в отдельные модели с суффиксом режима, `mergeCost()` мержит цены по тирам, `supports()` строит `Variant.Support` из `reasoning_options`. Периодический `refresh()` каждые 5 минут под `Semaphore.makeUnsafe(1)`, сравнивает `bodyDigest` (sha256) и молчит при побайтово том же теле. Есть `catalogModelStatus` = alpha/beta/deprecated.
- `model.ts` — каталог моделей поверх провайдеров. `Info`, `Ref`, `Capabilities`, `Cost` реэкспортируются из `@opencode/schema/model`; `mergeCapabilities()` дополняет частичные capabilities базой. Служба `Model.Service` строится на `State.create` со copy-on-write черновиками (`WeakSet` на карты и на модели). `read()` мержит провайдерские `settings`/`headers`/`body` в модель, сортирует по `time.released` и кэширует результат через `WeakMap` для неизменённых моделей; `available()` = включённые, `default()` = запрошенный или первый доступный, `small()` ищет семейства `gpt-luna`, `gemini-flash-lite`, `gemini-flash`, `claude-haiku`. Хелперы: `parse("provider/model")`, `compatibility()` (строка или `{ field }` → `reasoningField`).
- `variant.ts` — чистые функции, которые по пакету и по `reasoning_options` строят варианты рассуждения (`effort`, `toggle`, `budget_tokens`). Есть около 25 протоколов: `openaiChat`, `openaiResponses`, `anthropicMessages`, `gemini`, `bedrockConverse`, `openrouter`, `nvidiaChat`, `workersAIChat`, `basetenChat`, `deepinfraChat`, `deepseekChat`, `moonshotChat`, `alibabaChat`/`alibabaMessages`, `zaiChat`/`zaiMessages`, `minimaxMessages`, `sapAICore`, `vercelGateway`, `cloudflareAIGateway`, `cohere` и другие; таблица `PROTOCOLS` отображает пакет в протокол. Константы: `EFFORTS = ["low","medium","high"]`, `ANTHROPIC_OUTPUT_TOKEN_MAX = 32_000`, `ALIBABA_THINKING_BUDGET_MAX = 64_000`.
- `aisdk-native.ts` — перевод конфигурации с AI SDK-пакетов на нативные. `PACKAGES` (`@ai-sdk/anthropic` → `@opencode/ai/providers/anthropic` и ещё 16), `HOSTS` — перебор по `providerID` с `protocols(name)` (`chat`/`messages`/`responses`), `NATIVE` — множество «уже нативных». `rewrite()` подмешивает оверлеи в `settings`/`headers`/`body` и в варианты; `native()` и `resolve()` решают, во что превращается спецификатор. Отдельные переводчики: Bedrock (`bedrockSettings`, `bedrockThinking`, `bedrockRequest`), OpenRouter (`openRouterRequest` → `X-OpenRouter-Title`, `HTTP-Referer`, `X-Provider-API-Keys`). Валидация входа — схема `Legacy` на `StructWithRest` с `lenient()`-полями.
- `aisdk.ts` — мост к AI SDK. `locationLayer` даёт `Interface`: хуки `hook.sdk`/`hook.language` (регистрация с `Scope.addFinalizer`), кэш языковых моделей по `cacheKey` (функции сериализуются как `function:N`), `language()` и `model()`. `prepareOptions()` снимает из настроек `headerTimeout`, `chunkTimeout`, `compaction`, `transport` и подставляет свой `options.fetch`: таймер заголовков, `AbortSignal.any` из сигналов, слияние тела запроса через `mergeOverlay`, обёртка `wrapSSE` для таймаута между чанками SSE. `modelFromLanguage()` собирает `AnyRoute` с `protocol: "ai-sdk"`, `sanitizer: "none"`, `auth: Auth.none`, `endpoint` на `https://ai-sdk.local`, а `streamLanguage()` переводит `LanguageModelV3StreamPart` в `LLMEvent`, следя за открытыми фрагментами text/reasoning. Есть распознавание сетевых ошибок (`NETWORK_ERROR_CODES`, `NETWORK_ERROR_MESSAGES`, `networkFailure` с глубиной 4) и разбор ошибок провайдера (`decodeProviderError`).
- `model-resolver.ts` — превращает выбор каталога в готовую `LanguageModel`. `withVariant()` накладывает оверлей варианта без изменения снапшота, `fromCatalogModel()` валидирует: пакет поддерживается, `${VAR}` в `baseURL` разрешились (иначе `UnresolvedProviderVariablesError`), а политика `compaction: "native"` не обещает того, чего маршрут не умеет (`UnsupportedCompactionError`). `nativeCredentialSettings()` кладёт ключ туда, где пакет его ждёт: `apiKey`, `authToken` для anthropic, `accessToken` для google-vertex. `layer` зависит от Provider, Model, Integration, Npm, AISDK; при провайдере `activation: "enabled"`, отсутствии credential и API-ключевой авторизации маршрут переводится на `Auth.none`.
- `generate.ts` — одноразовая генерация текста без сессии. `Service.text({ prompt, model? })`: резолвит модель через `ModelResolver`, отправляет `LLM.request` с заголовком `x-opencode-session` (шлюзы требуют атрибуцию), ошибки переводит в `ModelSelectionError` или `UnavailableError`.
- `app.ts` — метаданные приложения: `Info { name, version, channel }`, `Context.Reference` с дефолтом `opencode/unknown/unknown`, `useragent()` вида `opencode/{channel}/{version}/{name}`, глобальный `node`.
- `agent.ts` — каталог агентов на `State.create`. `defaultID = "build"`. При создании агента к дефолтным правам добавляются четыре `external_directory` allow на каталоги global-данных, `shell/*/*`, `tool-output/*`, tmp и config. `selectedDefault()` пропускает агентов с `mode === "subagent"` и `hidden`; `list()` ставит выбранного первым; `select()` без аргумента отдаёт fallback `build`, даже если агента нет.
- `websearch.ts` — выбор и вызов провайдера веб-поиска. Выбор хранится в KV под ключом `websearch:provider` и может быть `false` (выключено), `"random"` или конкретным ID. В режиме `random` работает привязка к сессии `preferred` и кулдаун по HTTP 429: длительность берётся из `retry-after` (секунды, дата или 60 секунд по умолчанию). Ячейка `preferred` чистится по событиям `SessionEvent.Deleted` и `SessionEvent.Moved`.
- `formatter.ts` — запуск форматтера по расширению файла. `file(filepath)` берёт `path.extname`, для каждого совпадения резолвит команду (`formatter.enabled` может вернуть массив аргументов или `false`), подставляет `$FILE` и запускает процесс в `location.directory` с `extendEnv: true`. Команды кэшируются в `WeakMap` по объекту форматтера. Успех — код 0, иначе лог и попытка следующего форматтера.
- `image.ts` — нормализация картинок перед отправкой. Лимиты по умолчанию: autoResize включён, 2000×2000, 5 МиБ в base64. Адаптер `image/photon.js` грузится лениво и один раз (`Effect.cached`), при неудаче импорта — `ResizerUnavailableError`. Ошибки: `DecodeError` и `SizeError` с фактическими и предельными размерами в сообщении.

## Важные детали

- Разделение «core» и «провайдер»: `nativeSettings()` выкидывает `chunkTimeout`, `compaction`, `fetch`, `headerTimeout`, `timeout`, `transport` — нативные пакеты их не читают; `modelSettings()` убирает ещё и `transport`-связанные ключи при слиянии в модель.
- Таймауты транспорта, а не пакета: `model-resolver` переносит `Provider.timeouts(configured)` в `defaults.http` через `mergeHttpOptions`, а не в settings пакета.
- `mergeHeaders` сравнивает имена заголовков без учёта регистра, поэтому `Content-Type` и `content-type` — один ключ.
- `mergeOverlay` при отсутствии базы или оверлея декодирует значение как JSON-запись и может вернуть `undefined`, если запись пустая; вложенные объекты сливаются рекурсивно, скаляры перекрываются.
- Копирование при записи: `provider.ts` и `model.ts` не мутируют общие определения — карты и модели копируются перед первой правкой, результат `freeze(..., true)` (immer). В `provider.models.update` есть отдельная защита от замороженной (уже опубликованной) модели.
- `cacheKey` в `aisdk.ts` детерминирован по содержимому настроек; две функции с одинаковым телом получают разные id, одинаковая функция — один.
- `models-dev.ts` декодирует вшитый снапшот один раз на изолят (`bundledCache`), потому что снапшот занимает несколько МиБ и одна изолята может обслуживать много рантаймов. Запись в KV никогда не роняет загрузку — ошибка только логируется предупреждением.
- `variant.ts` не имеет состояния: одинаковый вход всегда даёт одинаковые варианты; `budgets()` уменьшает потолок на единицу относительно `model.limit.output` и возвращает пустой список, если максимум неположителен.
- `aisdk.ts` не умеет переигрывать нативную компакцию провайдера и форвардить ссылки на медиа (`source.type === "ref"`): обе ситуации дают явную ошибку, а не молчаливую потерю.
- Медиа из результата инструмента (картинки и PDF) `aisdk.ts` вынимает из `tool-result` и прикрепляет отдельным сообщением пользователя с текстом `Attached media from tool result:`; если других частей не осталось, вставляется текст `Media attached in the following user message.`
- `websearch.ts` при `choice === "random"` и всех провайдерах в кулдауне возвращает ошибку последнего, а не поднимает новый запрос; `default()` в этом режиме ничего не выбирает, чтобы не открывать согласие заново.

## Связи

- `models-dev.ts` → `variant.ts` (`Variant.resolve`) и `aisdk-native.ts` (`AISDKNative.native`): снапшот каталога уже несёт готовые варианты и нативные пакеты.
- `provider.ts` → `aisdk-native.ts`: `Editor.update` и `models.update` прогоняют каждую правку через `AISDKNative.rewrite`, поэтому ручная настройка не может оставить AI SDK-пакет.
- `provider.ts` → `integration.ts`, `credential.ts`, `bus.ts`, `location.ts`; `model.ts` → `provider.ts`, `bus.ts`, `state.ts`, `location.ts`.
- `model-resolver.ts` → `model.ts` (каталог и варианты), `provider.ts` (`loadPackage`, слияние настроек), `integration.ts` (активное соединение и credential), `npm` (установка пакета), `aisdk.ts` (`loadAISDK`).
- `aisdk.ts` → `model.ts` (только типы `ID` и `RuntimeInfo`), `provider.ts` (`isAISDK`, `packageName`, `timeouts`, `mergeOverlay`), `state.ts`, пакеты `@opencode/ai`, `@ai-sdk/provider`.
- `generate.ts` → `model-resolver.ts` и `@opencode/ai` (`LLMClient.generate`), плюс `effect/app-node-platform.ts` для клиента LLM.
- `agent.ts` → `bus.ts`, `state.ts`, `global.ts`; `formatter.ts` → `location.ts`, `app-node-platform.ts` (`AppProcess`); `image.ts` → `filesystem.ts`, `state.ts`; `websearch.ts` → `bus.ts`, `kv.ts`, `state.ts` и события сессий.

## Ловушки

- `Provider.packageName()` нужен почти везде: префикс `aisdk:` нельзя сравнивать с пакетом напрямую, а старые `@opencode-ai/ai/...` из пользовательского конфига чинятся только этой функцией.
- Список `builtins` в `provider.ts` и таблица `PROTOCOLS` в `variant.ts` — ручные: новый нативный пакет без записи в первой не загрузится, а без записи во второй не получит вариантов рассуждения.
- `model.package`, `model.modelID` и `model.id` — разные вещи: `id` это запись каталога (её показывают и хранят), `modelID` это идентификатор в API провайдера. В `model-resolver.ts` это же зафиксировано в комментариях к `Resolved.model` и `Resolved.ref`.
- Ошибки `model-resolver.ts` называются с префиксом `SessionRunnerModel.` — при поиске по тегу это не очевидно.
- `ai-sdk` маршруты используют `sanitizer: "none"`: санитайзеры семейств моделей выключены, конвертацию схем инструментов делает сам провайдер.
- `AISDK.language()` кэширует модель надолго: смена настроек без смены `cacheKey` даст старую модель; ключ включает `providerID`, `canonical`, `id`, `modelID`, `package`, `settings`, `headers`, `body`, `limit`.
- `HttpClient.filterStatusOk` в `models-dev.ts` стоит до `retryTransient`: ответ без статуса OK попадёт в повтор, а не в разбор.
- `Image` без адаптера `image/photon.js` падает на любом `normalize`, даже если файл маленький и ресайз не нужен: проверка импорта не ленивая по размеру.
- `Formatter.file` возвращает `true` только при коде 0; форматтер, который печатает в stdout, работает с `stdout: "ignore"` и вывода не увидит.
- `Agent.list()` меняет порядок — выбранный агент всегда первый, так что список нельзя сравнивать с исходным порядком конфигурации.
